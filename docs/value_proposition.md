# Value proposition

Sleep Support Bot helps users reduce friction around sleep preparation and recovery.

## Functional value

- fast scenario selection in Telegram
- short guided protocols
- power nap timer and alarm
- post-sleep check-in
- history and statistics
- premium personalization and deeper analytics

## Emotional value

- calm tone
- no pressure to perform sleep perfectly
- no fake medical promises
- transparent explanation of recommendations

## Differentiation

- Telegram-first, no separate install
- built-in privacy controls
- explainable recommendation logic
- simple mobile UX
