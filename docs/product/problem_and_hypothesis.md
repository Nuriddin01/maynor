# Problem and hypothesis

## Problem

People often want to fall asleep or recover quickly, but sleep apps are usually too heavy for the moment when the user is tired. Long onboarding, complex dashboards and aggressive claims create friction.

## Product hypothesis

If sleep support is delivered inside Telegram through short flows, clear buttons, gentle recommendations and simple check-ins, users will complete more sessions and return more often than in a standalone app.

## Success signal

- activation: first completed recommendation + first check-in
- retention: user returns within 7 days
- product value: recommendation helpfulness average above 3.7/5
- monetization: free-to-premium conversion after repeated usage
