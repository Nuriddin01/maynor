# Privacy Policy

This document is a project template and must be reviewed before production launch.

## Data we process

- Telegram user identifier
- username if available
- sleep check-in answers
- recommendation requests
- alarm settings
- preferences
- consent records
- subscription/payment events
- product analytics events

## Purpose

- provide sleep support flows
- create recommendations
- maintain history and statistics
- deliver alarms and reminders
- manage subscription access
- improve product quality through analytics

## Data minimization

The service does not request medical records, passport data, address, precise location or unnecessary sensitive data.

## User rights

Users can request:

- data export
- data deletion
- consent revocation
- marketing opt-out

## Disclaimer

Бот не заменяет врача. Если проблемы со сном стали постоянными или сильно мешают жизни, обратитесь к специалисту.
