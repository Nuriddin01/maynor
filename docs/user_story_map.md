# User Story Map

## Backbone

1. Discover bot
2. Give consent
3. Choose scenario
4. Complete short flow
5. Receive recommendation
6. Set alarm if needed
7. Complete check-in
8. View history/statistics
9. Upgrade to Premium
10. Manage privacy/settings

## MVP stories

- As a user, I can start the bot and accept required consent
- As a user, I can run night sleep preparation
- As a user, I can run power nap
- As a user, I can set an alarm
- As a user, I can complete wake check-in
- As a user, I can view 7/30-day stats
- As an admin, I can view analytics and content

## V2 stories

- weekly insights
- content packs
- custom routines
- richer admin content management

## V3 stories

- calendar-aware planning
- wearable integration
- multilingual CMS
- cohort experiments
