# Acceptance Criteria

## Рассчитать отбой

- Пользователь может нажать `🛏 Рассчитать отбой` после `/start`
- Если `wake_time` и хотя бы одна запись сна есть, бот считает `sleep_debt_minutes`
- Бот показывает `recommended_bedtime`, `target_wake_time`, `optimal_sleep_minutes_today`
- Если данных нет, бот использует базовый ориентир и явно пишет, что данных мало
- Рекомендация сохраняется в истории
- Бот предлагает включить напоминание

## Power nap / медитация

- Пользователь может выбрать `⚡ Power nap` или `🧘 Медитация`
- При наличии истории бот учитывает долг сна
- При отсутствии истории бот спрашивает свободное окно в минутах
- Для power nap длительность ограничена 10-20 минутами
- Для медитации длительность выбирается 5, 10 или 15 минут
- Рекомендация сохраняется в истории

## Быстро заснуть / хорошее пробуждение

- Пользователь может выбрать `💤 Быстро заснуть` или `🌅 Хорошее пробуждение`
- При наличии истории бот учитывает качество сна, длительность сна и время подъема
- При отсутствии истории бот спрашивает самооценку качества сна или пробуждения
- После рекомендации пользователь может сохранить оценку полезности
- Рекомендация и feedback сохраняются в истории

## Общие критерии

- Все тексты не обещают лечение и не ставят диагнозы
- Во всех релевантных сценариях есть дисклеймер
- Все данные хранятся локально в SQLite
- API работает без Docker через `python main.py`
